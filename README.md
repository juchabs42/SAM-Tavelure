# SAM Tavelure — V8

Fichiers à remplacer à la racine du dépôt GitHub Pages.

## Cette version ajoute
- le nouveau logo SAM Tavelure dans le bandeau, à droite du logo SudExpé ;
- le remplacement complet des favicons et icônes PWA par le nouveau logo ;
- un encard **Installer l'application** visible uniquement sur téléphone ;
- l'encard de connexion visible sur téléphone ;
- la compatibilité PWA conservée.
